# CHANGELOG v9 — Air Combat Plus

## Objetivo
Convertir la v8 en una base más potente y jugable, especialmente en combate aéreo, sin retroceder en el mini stage helicóptero → boss.

## Cambios principales
- Control arcade separado: `↑ / W` ahora es apuntar arriba, no saltar.
- Salto trasladado a botón de acción: `Z`, `J` o `Ctrl`.
- Disparo mantenido en `Space`, con alternativa `X`.
- Solucionado el problema de disparo diagonal: `↑ + ←/→ + Space` dispara diagonal sin saltar.
- Añadido aim assist suave para disparos hacia arriba y diagonal.
- Aumentada ligeramente la velocidad y vida útil de las balas para combate aéreo.
- Ajustados muzzle points de disparo diagonal y vertical.
- Actualizado HUD e instrucciones de control.
- Conservado mini stage: helicóptero primero, boss biomecánico después.

## Criterio de producción
- No se ha roto movimiento, escala, granada, debug, HUD, helicóptero, boss ni stage clear.
- El cambio de control se ha hecho para favorecer jugabilidad arcade real.
- El aim assist es suave: ayuda a leer el combate sin convertirlo en auto-disparo.
