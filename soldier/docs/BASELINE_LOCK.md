# Baseline de producción

Baseline recibido: `soldier_v02.zip`.

Principios:
- No retrocedemos.
- No nos dejamos nada.
- Revisamos antes de tocar.
- Cada cambio debe preservar movimiento, escala, salto, agachado, disparo, granada, partículas, debug y target holográfico.
- Si un cambio afecta a sensación arcade, se prueba con escala `0.26` y `0.38`.

Controles que deben seguir funcionando:
- `← / →`: mover
- `↑` o `W`: saltar
- `↓`: agacharse
- `Space`: disparar
- `G`: granada
- `Shift`: correr
- `1`: escala misión `0.26`
- `2`: escala boss `0.38`
- `+ / -`: ajuste fino
- `D`: debug
- `R`: reset
- `F`: pantalla completa
